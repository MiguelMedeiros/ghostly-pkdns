# Changes

What each published version of PKDNS Resolver changed, newest first. A version is published when its signed bundle,
`app.ghostlyapp`, is committed here and the [Ghostly store](https://github.com/MiguelMedeiros/ghostly-store) lists it.
`sequence` is the number Ghostly orders versions by.

## 1.0.1 (sequence 2)

- PKDNS Resolver has its own icon (`icon.png` in the bundle, 512 x 512): the Ghostly ghost holding a gold key in front
  of a globe, drawn by `scripts/icon.mjs`. Ghostly showed the generic app mark before. Nothing else changed.

## 1.0.0 (sequence 1)

The first version: the PKDNS Resolver extension as a Ghostly app, with signature checks of every relay answer and DNS
over HTTPS lookups.
